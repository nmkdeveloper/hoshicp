## Reporting a Vulnerability

Security is paramount for HoshiCP, particularly because it executes local compiler toolchains, child processes, and an embedded Competitive Companion receiver server.

If you discover a security vulnerability, **please do NOT report it in public GitHub Issues**. Instead, follow these steps:

1. **Privately report via GitHub Security Advisories** or email the maintainer at `nmkdeveloper`.
2. Include a detailed description of the vulnerability, including:
   - Affected version(s)
   - Step-by-step reproduction instructions or a Proof of Concept (PoC)
   - The potential impact on users (e.g., arbitrary code execution, path traversal, denial of service)
3. You will receive an initial response within 48 hours acknowledging receipt of your report.
4. Once verified, a security patch will be prepared and released promptly.

Thank you for responsibly disclosing security vulnerabilities and helping keep competitive programmers safe!
